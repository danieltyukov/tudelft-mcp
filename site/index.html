Your TU Delft courses, in your AI assistant.

tudelft-mcp is a small server that runs on your own computer. It gives Claude, ChatGPT, Cursor, Codex and any other MCP client access to your Brightspace courses, your official OSIRIS records, your MyTimetable schedule and the public Study Guide. You sign in once, in your own browser.

curl -fsSL https://danieltyukov.github.io/tudelft-mcp/install.sh | sh
irm https://danieltyukov.github.io/tudelft-mcp/install.ps1 | iex
npm install -g tudelft-mcp && tudelft-mcp setup && tudelft-mcp login

Node 20 or newer and a Chromium-based browser. Works with Claude Desktop, Claude Code, ChatGPT, Codex, Cursor, VS Code, Windsurf, Zed and Gemini CLI.

How it works
  1. InstallOne command installs the package and writes the MCP configuration for the clients it finds on your machine.
  2. Sign in onceYour usual browser opens the university login page. You type your password and MFA there, as always. Brightspace, OSIRIS and MyTimetable connect in that same window.
  3. AskOpen Claude, ChatGPT or your editor and ask about your courses. The session renews itself in the background for as long as the university session lasts.

Everything stays on your machine: the session, downloaded files and the search index live in ~/.tudelft-mcp. There is no hosted backend and no account with anyone but the university.

What it covers
Brightspace
Courses, content, announcements with attachments, assignments with your submissions and feedback, grades, calendar, quizzes, checklists, discussions, groups, locker files and lecture recording links. Slides, PDFs, Word, PowerPoint, Excel and notebooks are read in place.
OSIRIS
Official grades with a weighted average, study progress and programme structure, current registrations, catalogue search, course and exam details, and course or exam registration previewed before it is sent.
MyTimetable
Your personal schedule for any window up to 93 days with rooms, cancellations, UTC and Amsterdam local time, read from your own calendar feed. The feed URL is never shown to the model.
Study Guide and campus
Course descriptions, learning objectives and assessment without signing in, plus study spaces, teaching rooms, campus software and ICT notices.
Search and change tracking
sync_course indexes every file in a course; search_materials searches it; whats_new reports what changed since you last looked.
Write actions, carefully
Every write is a prepare_* tool that returns an exact preview and a one-use token, followed by a confirm_* tool. Nothing is submitted, joined, posted or registered without your approval of that preview.
Compared with the earlier project

tudelft-mcp started as a rewrite of the earlier my-tudelft-mcp project, which mapped the university APIs first. The differences are mostly in how it installs and stays signed in.

my-tudelft-mcptudelft-mcp
Installgit clone plus a 300 MB Chromium downloadOne command, using the browser already installed
Sign-inThree separate loginsOne login in one window
RenewalEach service refreshed on its ownSilent renewal from a shared profile, verified live
ClientsCodex firstEvery MCP client, including ChatGPT over HTTP
Search indexSQLite through an experimental Node modulePlain JSON index, no native modules
Tools8466, with fewer duplicates
Privacy
  • Runs locally only. Nothing is sent anywhere except to the university's own services.
  • Cookies, tokens and the calendar feed URL never appear in tool output.
  • Your password and MFA are typed only in the university's own login page.
  • Downloads and the search index stay under ~/.tudelft-mcp with owner-only permissions.
  • tudelft-mcp logout removes the saved sessions and the browser profile.
Questions
Which Node version do I need?

Node 20 or newer. The installer checks and tells you where to get it.

Which browsers work?

Google Chrome, Microsoft Edge, Chromium or Brave, already installed. Without any of them, tudelft-mcp browser install downloads a Chromium build.

Does it work on Windows?

Yes. The session file is additionally wrapped with Windows data protection for your user account. CI runs on Windows, macOS and Linux.

How do I connect ChatGPT?

Run tudelft-mcp serve --http --tunnel. It prints a URL to paste into ChatGPT's connector settings. Desktop clients can stay connected at the same time.

Can it submit assignments?

Only after showing you an exact preview (files, hashes, comment, assignment) and only when you confirm that preview. The same applies to group joins, discussion posts and OSIRIS registrations.

Is this official?

No. It is an independent open source project and is not affiliated with TU Delft.
