Your TU Delft courses, in your AI assistant.

tudelft-mcp is a local MCP server that connects Claude, ChatGPT, Cursor and other assistants to your Brightspace courses, your official OSIRIS records, your MyTimetable schedule and the public Study Guide, after one sign-in in your own browser.

curl -fsSL https://danieltyukov.github.io/tudelft-mcp/install.sh | sh
irm https://danieltyukov.github.io/tudelft-mcp/install.ps1 | iex
npm install -g tudelft-mcp && tudelft-mcp setup && tudelft-mcp login

Works with Claude Desktop, Claude Code, ChatGPT, Codex, Cursor, VS Code, Windsurf, Zed, Gemini CLI.

How it works

  1. Install

    One command installs the package and writes the MCP config for the clients it finds on your machine. Node 20 or newer and a Chromium-based browser are all it needs.

  2. Sign in once in a browser window

    Your usual browser opens on the university login page. Enter your password and MFA there, as you always do. Brightspace, OSIRIS and MyTimetable connect in that same window.

  3. Ask your assistant

    Open Claude, ChatGPT or your editor and ask about your courses. The session renews itself in the background for as long as the university session lasts.

Everything stays on the machine. The session, downloaded files and the search index live in ~/.tudelft-mcp. There is no hosted backend.

Features

Brightspace

  • Courses, content tree and announcements with attachments.
  • Read slides, PDFs, Word, PowerPoint, Excel, notebooks and captions in place with read_material.
  • Assignments, your submissions and feedback files; grades and the calendar.
  • Quizzes, checklists, discussions, groups, locker files and recordings.

OSIRIS

  • Official grades and weighted average with osiris_grades.
  • Study progress, programme structure and current registrations.
  • Course catalogue search, course details and exam opportunities.
  • Course and exam registration, previewed before it is sent.

MyTimetable

  • get_timetable for any window up to 93 days.
  • Rooms, cancellations, UTC and Amsterdam local time on every event.
  • Uses your personal calendar feed; the feed URL is never returned to the model.

Study Guide and campus

  • Search and read course descriptions without signing in.
  • Study spaces, rooms, campus software and ICT notices.

Local search and change tracking

  • sync_course downloads and indexes every file in a course, resumably.
  • search_materials runs a BM25 search over the index on disk.
  • whats_new reports announcements, files, due dates and grades that changed since the last check.

Safe write actions

  • Every write is two tools: prepare_* returns an exact preview and a one-use token that expires in five minutes; confirm_* sends the request once.
  • Covers assignment submission, group join, discussion reply and OSIRIS registration.
  • An uncertain outcome is reported, never retried.

Compared with the original

tudelft-mcp started as a rewrite of the earlier my-tudelft-mcp project, which mapped the university APIs first. The differences are in how it installs and stays signed in.

The earlier my-tudelft-mcp project tudelft-mcp
Install git clone plus a 300 MB Chromium download One command, using the browser already installed
Sign-in Three separate logins One login in one window
Renewal Each service refreshed on its own Session refresh from a shared browser profile, for as long as the university session lasts
Clients Codex first Every MCP client, including ChatGPT over HTTP
Search index SQLite through an experimental Node module Plain JSON index, no native modules
Tool count 84 66, with fewer duplicates

Privacy

  • Runs only on your machine. There is no server in between you and the university.
  • Cookies, tokens and the calendar feed URL are never returned to the model. Query strings that look like credentials are stripped from every link.
  • Your password and MFA are typed only in the university's own login page, inside the browser window.
  • Downloads and the search index live under ~/.tudelft-mcp, readable by your user account only.
  • tudelft-mcp logout removes the saved sessions and the browser profile.

Questions

Which Node version do I need?

Node 20 or newer. The installers check for it and tell you where to get it if it is missing. Node 22 is what the project is developed and tested on.

Which browsers work?

Google Chrome, Microsoft Edge, Chromium or Brave, whichever is already installed. On a machine without any of them, tudelft-mcp browser install downloads a Chromium build. Set TUDELFT_BROWSER_PATH to pick a specific executable.

Does it work on Windows?

Yes. The PowerShell installer sets it up, and the saved session is wrapped with Windows Data Protection (DPAPI) for your user account. Claude Desktop, Cursor, VS Code, Codex and the other clients are configured the same way as on macOS and Linux.

How do I connect ChatGPT?

ChatGPT connects over HTTP rather than stdio. Run tudelft-mcp serve --http --tunnel. It starts the Streamable HTTP transport with a bearer token and, when cloudflared is installed, prints a public URL to paste into ChatGPT's connector settings together with the token. The desktop clients can stay connected at the same time.

Can it submit assignments?

Only after a preview and your explicit confirmation. prepare_submission returns exactly what would be sent (assignment, file, size, comment) and a token that is valid for five minutes. Nothing is uploaded until confirm_submission is called with that token and confirmed: true, and the assistant is instructed to show you the preview first. The same applies to group joins, discussion replies and OSIRIS registrations.

Is this official?

No. tudelft-mcp is an independent open source project and is not affiliated with or endorsed by TU Delft. It uses the same web APIs as the Brightspace, my.tudelft.nl and MyTimetable web apps, from your own account, on your own machine.
